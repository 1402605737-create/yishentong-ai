# 医审通 AI MVP PRD

## 目标用户

- 医院医保办审核人员
- 互联网医院运营
- 商保预授权专员
- 医疗信息化售前和解决方案团队

## MVP 场景

影像检查 MRI/CT 的事前审核与补件建议。

## 核心流程

1. 审核人员查看脱敏案件和材料清单。
2. 系统检索医保/商保中文政策条款。
3. 规则引擎检查确定性材料要求。
4. DeepSeek V4 Flash 生成中文审核摘要、补件说明和人工复核原因。
5. Harness 安全闸门阻止高风险案件被误判为可提交。
6. 评测看板展示缺件召回、政策引用扎根、误放行率和延迟。

## 不做

- 不做诊断。
- 不自动批准或拒绝医疗服务。
- 不处理真实患者 PHI。
- 不跳过人工复核。

## 关键指标

- 缺件召回率
- 误放行率
- 政策引用扎根率
- 审核说明中文可读性
- 平均延迟和模型成本
