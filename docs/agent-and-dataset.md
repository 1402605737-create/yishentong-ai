# 案件库与审核 Agent

## 案件库规模

当前内置中文合成案件库共 183 条，覆盖 6 个审核方向：

- 腰椎 MRI：31 条
- 膝关节 CT：31 条
- 头颅 CT：31 条
- 冠脉 CTA：30 条
- 无痛胃肠镜：30 条
- 肿瘤靶向药：30 条

每条案件都包含脱敏患者摘要、医院、城市、医保/商保主体、诊断、申请项目、临床摘要、材料清单、政策绑定和初始状态。

## Agent 能力

审核 Agent 不是单次模型调用，而是一个可追踪的多步骤执行链：

1. 读取脱敏案件快照：加载案件、申请项目和材料清单。
2. 检索中文政策：根据 payer、项目和诊断匹配医保/商保条款。
3. 执行规则校验：检查材料完整性、缺件、加急风险和政策引用。
4. 生成中文审核意见：单案可调用 DeepSeek V4 Flash，批量演示默认走本地 harness。
5. 安全闸门与路由：阻止高风险案件被直接建议提交，并路由到补件或人工复核。

前端“案件预审工作台”支持批量 Agent 审核。点击“批量Agent审核”后，可以看到待审数量减少、已处理数量增加，并在右侧详情页查看 Agent 执行链和 trace。
