# 提示词实验台

提示词实验台用于展示 AI PM 的迭代能力：同一个 `deepseek-v4-flash` 模型下，对比“召回优先、均衡策略、成本优先”三种中文审核策略，并输出缺件召回、政策引用扎根、误放行率、延迟、成本和灰度建议。

## 候选策略

- P1 严格召回版：优先降低误放行风险，适合医保事前审核和急诊高风险场景。
- P2 均衡审核版：兼顾缺件召回、引用质量和人工复核压力，适合日常预审队列。
- P3 成本速度版：降低单案延迟和模型成本，适合低风险材料初筛，不建议直接上线到高风险场景。

## 面试讲法

这个项目不是只调一个 prompt，而是把 prompt 版本管理、A/B/C 策略对比和上线闸门放进同一个 harness 里。策略是否上线由评测指标决定，而不是由单个 demo 输出决定。
